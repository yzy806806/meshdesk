## 2. Config Loading/Validation/Save Pipeline

All in `internal/config/config.go`.

### Load (`config.Load(path)`: line 703)
1. `os.ReadFile(path)` — reads raw YAML bytes
2. `yaml.Unmarshal(data, cfg)` — unmarshals on top of `Default()` (so missing fields get defaults)
3. ~70 lines of zero-value defaulting (lines 720-878):
   - Port defaults: mesh=51820, gossip=7946, monitoring=4191, webssh=2222
   - Interval defaults: monitoring=15s, P2P gossip=30s, probe=1s
   - Only applied when P2P.Enabled=true for P2P fields
   - Proxy defaults: chunker="bounded-4k-64k", circuit timeouts (300/30/5/30/256), SS port=8388, relay jitter (5/50ms)
   - CF Tunnel defaults: origin_server="127.0.0.1:8388", log_level="warn", metrics_addr="127.0.0.1:36500"
4. Legacy TOTP secret detection (line 714): extracts deprecated `auth.totp_secret` for one-time migration
5. **No schema validation** — no enum validation (RelayMode checked for "" only), no port range checks, no key format verification, no duplicate peer detection. Validation is purely "if zero, set default."

### Save (`config.Save(path, cfg)`: line 883)
1. `yaml.Marshal(cfg)` — serializes ALL fields including auto-generated identity keys
2. `os.WriteFile(path, data, 0600)` — restrictive permissions
3. **Currently unwired** — no HTTP endpoint calls this. Only discoverable via static analysis.

### Hot-reload: NONE
Config is loaded once at `main.go:61`. The `*config.Config` pointer flows to subsystems (mesh.New, p2p.NewGossipLayer, web.New). Runtime changes require process restart. There is no SIGHUP handler, no file watcher, no `/api/config/reload` endpoint.

## 4. Security-Sensitive Config Fields

### CRITICAL — Editing could lock admin out
| Field | Risk |
|---|---|
| `auth.web_users[].password_hash` | Wrong bcrypt hash → no login possible |
| `auth.require_2fa` | Enabling without enrolled users → permanent lockout |
| `node.web` (WebAddr) | Changing port mid-session kills HTTP listener; browser redirects fail |

### HIGH — Exposure risk (private keys / secrets)
| Field | Risk |
|---|---|
| `node.identity` | WireGuard private key. Exposure = impersonate node, decrypt all mesh traffic |
| `reality.private_key` | X25519 server key. Exposure = attacker authenticates as Reality server |
| `proxy.ss.password` | Shadowsocks PSK. Exposure = decrypt SS traffic |
| `peers[].preshared_key` | WG PSK per peer. Exposure = break Noise IKpsk2 post-quantum resistance |
| `peers[].obf_config.psk` | Anti-probe PSK. Exposure = attacker can craft valid handshake initiations |
| `reality.short_ids` | If leaked, attacker can authenticate as a valid Reality client |

### MEDIUM — Should be read-only or require step-up auth
| Field | Risk |
|---|---|
| `peers[].public_key` + `peers[].allowed_ips` | Misconfiguration breaks mesh routing; affects connectivity not security |
| `auth.totp_store_dir` | Changing path = lose all enrolled TOTP secrets without warning |
| `p2p.authorized_keys` | Removing a key silently drops a node from the mesh |
| `proxy.exit.allowed_ports` / `allow_all_ports` | Legal liability for exit node operators |
| `auth.alert_webhook_url` | Attacker could redirect alerts to attacker-controlled endpoint |

### SAFE — Safe to edit via UI without special protections
- `node.hostname` — cosmetic
- `node.position` — display-only metadata
- `mesh.port` — requires listener restart but not security-sensitive
- `mesh.gossip_port`
- `p2p.seeds`, `p2p.stun_servers`, `p2p.gossip_interval`, `p2p.max_peers`
- `monitoring.interval`, `monitoring.port`
- `webssh.*` (all fields are tuning parameters)
- `transfer.*`
- `proxy.circuit.*`, `proxy.path_selection.*` (tuning)
- `xray.*` (already UI-editable)
- `reality.dest`, `reality.server_names`, `reality.listen_addr` (non-secret fields)

### Hot-reload integration
`config.Save()` exists at line 883 but is unused. For hot-reload:
1. The `/api/config/*` endpoints call `config.Save("/etc/meshdesk/config.yaml", cfg)`
2. A new `config.Reload(newCfg)` method notifies subsystems via a `ConfigNotifier` interface
3. Subsystems that support hot-reload (P2P, monitoring, webssh params) implement the notifier
4. Subsystems that require restart (mesh.port, node.identity, reality listener) return an error with the restart-required list
5. The UI shows a "Restart required for: mesh port, reality config" banner after save
